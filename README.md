12-week self-taught roadmap toward building an AI-powered portfolio project.

## Projects Built
- 🚀 **[AI Internship Fit Scorer (LIVE)](https://cv-scorer-first.streamlit.app/)** — Streamlit web app that uses Groq (Llama 3) to analyze student skills vs internship requirements and generates recruiter-style gap analysis.
- `internships.py` — SQLite skill matcher: compares student skills vs internship requirements.
- `city_weather.py` — Reads Moroccan cities from file, fetches live weather via Open-Meteo API.
